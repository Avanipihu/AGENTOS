Security Invariants
1. Zero Information Leakage: Protection rules are evaluated before path existence resolution. An unauthorized agent gets DENIED without discovering whether a file exists.
2. Longest-Prefix Specificity: More specific path prefixes override broader root permissions (e.g. /workspace/notes overrides /workspace).
3. Optimistic Concurrency: Writes enforce optional version matching to eliminate lost updates in shared agent workspaces.
